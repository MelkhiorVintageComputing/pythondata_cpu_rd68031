# pythondata-cpu-rd68031

The SystemVerilog of [RD68031](https://github.com/MelkhiorVintageComputing/RD68031),
an MC68030, packaged for LiteX (`get_data_mod("cpu", "rd68031")`).

Generated by `litex-68k/scripts/sync_pythondata.sh` from RD68031 commit
`5e22ddca9dbb6d0399eb9e9377e75050508e644d` (`5e22ddc`). Do not edit; regenerate.

- `pythondata_cpu_rd68031/verilog/rtl/`: the RTL, as in RD68031's `rtl/`.
- `pythondata_cpu_rd68031/verilog/rd68031.f` and `pythondata_cpu_rd68031.sources`: the files in compile order.
- `pythondata_cpu_rd68031/verilog/rtl/rd68031.vlt`: RD68031's Verilator waivers.
- `pythondata_cpu_rd68031/verilog/rd68884/`: the FPU, [RD68884](https://github.com/MelkhiorVintageComputing/RD68884)
  commit `7ec30da7f7f2af26ac0f068c0b72f08db8d83cf0`, its MC68881 build (`pythondata_cpu_rd68031.fpu_sources`, `rd68884.f`), as it is.
